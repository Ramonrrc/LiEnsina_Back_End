# LiEnsina Back End

API NestJS para o LiEnsina com banco JSON proprio para o dominio escolar.

## Credenciais locais

- `secretaria@liensina.local`
- `diretor@liensina.local`
- `professor@liensina.local`

Nesta versao inicial, a senha de cada usuario e o proprio e-mail.

## Comandos

```bash
npm install
npm run start:dev
```

A API sobe em `http://localhost:3001/api`.
